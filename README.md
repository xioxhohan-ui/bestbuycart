# Best Buy Cart — Global Product Discovery Platform

> **"Discover. Compare. Decide."**

Best Buy Cart is a global product discovery, price tracking, comparison, and community review web platform built with **React 18**, **TypeScript**, **Vite**, **Vanilla CSS Design System**, and **Supabase (PostgreSQL)**.

---

## 🌟 Platform Features (Parts 1 to 10)

1. **Trending Engine**: Viral product velocity algorithm, worth scores, and real-time hype meters.
2. **Categories Engine**: 14 top-level category hubs with deep subcategory trees and editor picks.
3. **Discovery Engine & Master Admin Panel**: Hidden Gems, Overhyped Watch, AI Finder, and a WordPress/cPanel-style Master CMS at `/shohan` (Password: `shohan555`).
4. **Comparison Engine**: Side-by-side spec comparison matrix, difference highlighting, and verdict badges.
5. **Deals & Price Tracking Engine**: 30-minute automated price drop radar, deal verification, and target price alerts.
6. **Gift Finder Wizard**: Empathetic recommendation wizard based on recipient persona, occasion, and budget.
7. **Content Engine & SEO Intelligence**: Editorial buying guides, internal link graph, and content refresh workflow.
8. **Professional UI & Zero-Emoji Standard**: Built strictly with Lucide SVG iconography for US & EU market standards.
9. **User Accounts & Community Engine**: User dashboards, saved wishlists, price watchlists, verified customer reviews, and a 4-tier loyalty reputation system (`Novice Explorer` ➔ `Master Curator`).
10. **Dynamic Navigation & Mega Menu System**: Database-driven desktop mega menu, tools dropdown, and mobile drawer managed via `/shohan/menu`.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Vanilla CSS with custom tokens & glassmorphism components
- **Icons**: Lucide React (Zero-Emoji Compliance)
- **Database & Backend**: Supabase (PostgreSQL 17 with Row-Level Security)
- **State Management**: React Context (`NavigationContext`, `AuthContext`, `SearchContext`)
